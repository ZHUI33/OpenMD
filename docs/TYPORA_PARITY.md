# OpenMD 专注写作体验对标

> 目标不是复制 Typora 的品牌、主题、代码、图标或像素级界面，而是让 OpenMD
> 具备同等级的低干扰写作、连续 Live Preview、自然键盘操作和桌面软件质感。
>
> 基线（2026-07-27）：`pnpm lint`、`pnpm typecheck`、`pnpm test` 全部通过，
> 34 个测试文件 / 239 项单元测试通过；改造前界面已通过实际 Electron 启动截图检查。

## P0 验收操作

1. 打开文件夹后，在左侧顶部切换“文件 / 搜索 / 大纲”；正文宽度只受一个侧栏影响。
2. 拖动侧栏右边缘验证宽度限制在 220–420px；折叠后重新打开仍保留宽度和面板。
3. 选择正文文字，依次使用浮动工具条和 Ctrl/Cmd+B、I、K；切换源码确认生成标准 Markdown。
4. 普通点击链接不会离开编辑器；Ctrl/Cmd+点击通过系统默认浏览器打开允许的 URL。
5. 在文件树中用按钮或右键菜单新建、重命名；Enter 确认、Escape 取消。
6. 删除文件或文件夹时确认目标名称；回收站失败只显示错误，目标仍存在。
7. 关闭并重新启动应用，确认侧栏显示状态、宽度和当前面板恢复。
8. 在浅色、深色、窄窗口以及 100%、125%、150% 缩放下检查无重叠和水平溢出。
